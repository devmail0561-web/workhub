# Frontend WorkHub

Interface web React (Vite + TypeScript strict, Tailwind, shadcn/ui, TanStack Router/Query).

Le squelette applicatif est prévu par la tâche **E0-11** du plan de développement.

## Prérequis

- Node.js 20+

## Commandes (une fois le squelette en place)

```bash
npm install
npm run dev
npm run build
npm run test
```
